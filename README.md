# 🍸 BarMatch - MVP de Gestión de Aforo y Reservas en Tiempo Real

BarMatch es una solución tecnológica integral diseñada para resolver la asimetría de información y los cuellos de botella en la gestión de aforo del rubro del entretenimiento nocturno. 

Este repositorio contiene el Producto Mínimo Viable (MVP) desarrollado como proyecto de titulación en Ingeniería en Informática. El sistema implementa una arquitectura escalable orientada a manejar alta concurrencia transaccional, dividida en un modelo de negocio B2C (aplicación móvil para exploración y reserva de usuarios) y B2B (panel de control web para la gestión de capacidad y validación de accesos vía códigos QR por parte de los locatarios).

**Características Técnicas Principales (Core):**
- Gestión de base de datos relacional para usuarios y reservas.
- Manejo de concurrencia y aforo en tiempo real.
- Sistema de validación de entradas seguro mediante escaneo de QR.
- Arquitectura desplegada en servicios Cloud (SaaS/PaaS).
