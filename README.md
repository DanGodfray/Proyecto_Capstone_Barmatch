# 📌 BarMatchIA - Proyecto Capstone

BarMatchIA es una plataforma digital integral que conecta a personas en búsqueda de experiencias gastronómicas y de entretenimiento con establecimientos que necesitan gestionar su disponibilidad de manera inteligente[cite: 19]. El proyecto aborda el problema de la incertidumbre al salir, unificando el descubrimiento de locales y la reserva en un solo lugar[cite: 18]. A su vez, entrega a los administradores herramientas avanzadas para transformar sus datos operacionales en conocimiento estratégico[cite: 18, 19].

## 🎯 Propuesta de Valor y Modelo

El ecosistema opera bajo un modelo B2B2C, donde el acceso es gratuito para el usuario final, disminuyendo barreras de adopción, mientras que el modelo de sostenibilidad se enfoca en los establecimientos[cite: 18]. 

La plataforma soluciona necesidades críticas en ambos extremos: permite al cliente explorar, consultar disponibilidad en tiempo real y asegurar su lugar, eliminando la frustración de llegar a recintos sin capacidad[cite: 18, 19]. Para el local, centraliza la recepción de clientes, el seguimiento de cancelaciones y provee un panel administrativo que reemplaza la gestión manual[cite: 18, 19].

## 👥 Mapa de Actores y Responsabilidades

El sistema organiza su funcionamiento a través de cuatro niveles de interacción humana, cada uno con alcances definidos:

*   **Cliente Final:** Explora alternativas por temática, consulta la disponibilidad de espacios, realiza reservas y valida su ingreso al local utilizando un código QR[cite: 17, 18].
*   **Personal del Local:** Opera un panel diario para validar llegadas, gestionar clientes sin reserva previa (*walk-ins*) y asignar mesas en tiempo real[cite: 17, 18].
*   **Administrador del Local:** Supervisa el recinto configurando horarios y mapas visuales de mesas, mientras consume reportes de rendimiento y sugerencias[cite: 17, 18].
*   **Administrador de Plataforma:** Mantiene el control global del software, moderando contenido, gestionando estados y habilitando el acceso a nuevos locales comerciales[cite: 17].

## 🧠 Ecosistema Inteligente (IA) y Desarrollo Técnico

BarMatchIA se diferencia de una simple agenda al implementar capacidades de análisis de datos estructuradas en tres niveles progresivos:

*   **Analítica Descriptiva:** Procesa historiales para identificar los horarios de mayor demanda y las tasas habituales de ocupación[cite: 19].
*   **Analítica Predictiva:** Utiliza Machine Learning para estimar la cantidad de clientes esperados y calcular probabilidades de cancelación[cite: 19].
*   **Recomendaciones:** Entrega sugerencias fundamentadas en datos para optimizar los periodos recurrentes de baja demanda[cite: 19].

Actualmente, el proyecto se encuentra en la etapa de definición funcional y modelamiento de dominio (*User Story Mapping*), manteniendo el *stack* tecnológico deliberadamente abierto para alinear la arquitectura a las verdaderas reglas de negocio[cite: 18].
